- `stage1/`: the menus after stage 1 (purple base, rail layout, new components), including 1920x1080 and 390x760 phone captures.
- `stage2/`: the results screen with sample data.
- `stage3/`: the in-race HUD (sample data from `?hud=sample`), pause, online room, Tab board and touch layouts.
