# UI screenshots

Headless captures from the dev build (software renderer, so frame rate and colour can differ from a real browser). Most are 1280x640. Sample data where a race or lap would be needed.

- `before/`: the menus before the UI redesign.
- `v2/`: the current quiet design (iRacing-style: flat panels, thin borders, one solid purple button, upright type). It replaced a first, louder design that was rejected.
- `menu-flow/`: the menu as a front screen (Race, Garage, Leaderboard, Settings), the Race cards, pause and settings; d = 1280x720, t = 1024x768 touch, p = 390x760 phone.
